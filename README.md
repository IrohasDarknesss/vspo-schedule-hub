# 🎮 VSPO! SCHEDULE (ぶいすぽジュール)

ホロジュール（Holodule）のような操作感で、「ぶいすぽっ！」(JP) および「VSPO! EN」所属タレントの動画配信予定・ライブ配信・過去配信アーカイブをまとめてチェックできる総合スケジュールWebアプリケーションです。

---

## ✨ 主な機能

### 1. 📅 ホロジュール風スケジュールタイムライン
- **日付ナビゲーション**: 「昨日」「今日 (LIVE中)」「明日」「週間予定」をタブで素早く切り替え。
- **リアルタイム状態バッジ**:
  - 🔴 **LIVE NOW**: 現在配信中の枠が赤く点滅し、同時視聴者数や経過時間を表示。
  - ⏰ **UPCOMING**: 開始カウントダウン（「あと18分」「明日 19:00」など）を表示。
  - 📁 **ENDED**: 配信アーカイブを再生時間付きで表示。
- **ゲームタイトル・検索フィルター**: VALORANT, Apex, Street Fighter 6, Overwatch 2, Minecraft, 歌枠, 雑談などお好みのゲームで絞り込み。

### 2. 🌐 VSPO! ENメンバー完全対応
- **ワンクリック支部切り替え**: 「ALL (全メンバー)」「JP ぶいすぽっ！」「VSPO! EN」を即座にフィルタリング。
- **VSPO! EN Spotlight**: 青月レミア (Remia Aotsuki)、黒羽アリヤ (Arya Kuroha)、ジラ・ジス (Jira Jisoo)、神楽みくれ (Narin Mikure) などENメンバーの配信をハイライト。
- **世界対応タイムゾーン変換**: JST (日本標準時)、UTC、EST (米東部)、PST (米西部)、CET (中央欧州)、KST (韓国) にワンクリックで切り替え。配信時間が自動で現地時間に換算されます。

### 3. 🚀 ワンクリックで配信へジャンプ
- 各配信カードの「今すぐ配信を見る / アーカイブを視聴」ボタンをクリックすると、**YouTube / Twitchの配信ページに直接アクセス**できます。
- コラボ配信では参加メンバーのアバターが並び、クリックするとそのメンバーの過去配信ページへジャンプできます。

### 4. 📺 タレント詳細 ＆「過去5回分の配信アーカイブ」
- 「タレント＆過去配信」タブ、または配信カードのメンバーアイコン・名前をクリックすると詳細画面が展開。
- **過去5回分の配信アーカイブ (Last 5 Streams)**:
  - 配信サムネイル・タイトル
  - 配信日時・再生時間
  - 視聴回数・ゲームタグ
  - **「配信を見る」直接視聴リンクボタン**
- タレントの公式YouTube、Twitch、Twitter(X)リンク、登録者数、ユニット情報、今後の配信予定も掲載。

### 5. ⭐ 推し（お気に入り）機能 ＆ カレンダー登録
- メンバーの「★」を押すとブラウザ（localStorage）に推しとして保存。
- 「推し」タブで推しメンバーだけの配信スケジュールとアーカイブを一括管理。
- 配信詳細から Googleカレンダー / .ics (Apple・Outlook) に配信リマインダーを1クリックで追加可能。
